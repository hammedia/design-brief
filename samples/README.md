# Design Brief Form Samples

이 폴더는 공개 도구의 생성 품질을 확인하기 위한 샘플 보관소입니다.

## 공개 규칙

- 가짜 데모 채널과 테스트 답변으로 만든 결과물만 보관합니다.
- 실제 손님, 고객사, 상담 내용, 설문 답변, 생성 결과물은 절대 넣지 않습니다.
- 공개 페이지나 GitHub Pages에 올라가도 문제 없는 자료만 남깁니다.

## 현재 세트

- `20260619_generation-upgrade-evidence/education-warm/`: 따뜻한 교육형 테스트
- `20260619_generation-upgrade-evidence/vibrant-content/`: 활기있는 콘텐츠형 테스트

각 세트는 프롬프트 개선 전 `before`와 개선 후 `after`를 비교하기 위해 보관합니다.
